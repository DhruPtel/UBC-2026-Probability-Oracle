Agent insurance desk

Declared holdingOrder ticket: not sentSandboxData provided by Gemini

An agent signs up with what it holds and gets an Arc testnet wallet with test USDC. It pays $0.001 over x402 for each odds read, browses Gemini’s live contracts that match its holding, and buys cover: each contract pays $1 if the bad outcome happens. The premium is real testnet USDC, paid onchain to the treasury through ProtectionBook.

The holding is declared, not held. The Gemini order is an order ticket: the exact body for Gemini’s order API at its live price, not sent, because that needs a funded US account. The same order is placed in Gemini’s sandbox with test funds when the sandbox lists the contract. Demo wallets are a pool of four, reused by one agent after another.

Any MCP client can use the desk. For Claude Code, run this once, then ask Claude to insure a BTC or ETH holding. The Lab server must be running; your agent then appears here as “Your agent”.


    
Or add this to an MCP config file:

    

    
Tools: sign_up, check_risks, list_contracts, quote_cover, buy_cover, my_cover.
